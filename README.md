TicketsGold — versión conectada a Supabase

Incluye:
- Registro con email y contraseña.
- Inicio de sesión con Supabase Auth.
- Botón de cuenta cambia a “Mi cuenta” cuando existe sesión.

Variables de Vercel:
NEXT_PUBLIC_SUPABASE_URL
NEXT_PUBLIC_SUPABASE_ANON_KEY

Nota: esta versión usa la Publishable key de Supabase en el frontend, que está diseñada para uso público. Nunca incluir Secret keys.
